# 기능·사용자 흐름·범위

필요시 확인: 기능 추가·수정, 업무 규칙·완료 조건 확인.

적용 범위: 공통 정의 항목. 다음 구현 단위를 정할 만큼 구체화한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 핵심 흐름 | 시작 조건 → 사용자 행동 또는 입력 → 기대 결과 | 미정 |
| 기능과 우선순위 | 반드시 필요한 것, 나중에 추가할 것, 기능 간 선후관계 | 미정 |
| 포함·제외 범위 | 이번에 할 일과 의도적으로 하지 않을 일 | 미정 |
| 도메인 규칙 | 상태 전환, 계산, 날짜·단위 등 틀리면 안 되는 업무 규칙 | 미정 |
| 오류·경계 상황 | 빈 입력, 취소, 중복, 잘못된 값, 실패 시 사용자 기대 | 미정 |
| 완료 조건 | 요구사항별 확인 가능한 동작과 결과 | 미정 |
