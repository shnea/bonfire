# 보안·인증·권한·개인정보

필요시 확인: 입력 경계·인증·권한·공유·민감정보를 다룰 때.

적용 범위: 입력·비밀정보 처리는 해당 경계에서 검토한다. 계정·역할·개인정보 절차는 실제 필요할 때만 적용한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 접근 범위 | 로컬·내부·공개 여부, 외부 입력과 신뢰 경계 | 미정 |
| 인증 | 로그인 필요 여부, 기존 인증 서비스, 세션·계정 수명 | 미정 |
| 권한·공유 | 누가 무엇을 읽고 변경하는지, 사용자·조직 간 데이터 분리 | 미정 |
| 개인정보·민감정보 | 필요한 수집 범위, 보관·삭제·노출 방지 | 미정 |
| 설정·비밀값 | 환경별 설정, 비밀값 보관·주입, 로그에서 제외할 값 | 미정 |
