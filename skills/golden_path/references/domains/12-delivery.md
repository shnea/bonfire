# Git·릴리스·배포

필요시 확인: 커밋·푸시·릴리스·배포를 요청받았거나 관련 구성을 변경할 때.

적용 범위: Git·릴리스·배포를 사용하는 범위에 맞게 적용한다. 설치형 앱·패키지는 배포 대상을 그에 맞게 바꾼다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 브랜치와 검토 | main 중심·작업 브랜치·PR, 변경 검토 기준 | 미정 |
| 커밋·푸시 | 시점·포함 범위·위임 범위, 기존 변경의 처리 | 미정 |
| 버전과 산출물 | 버전 식별, 재현 가능한 빌드, 게시·보관 대상 | 미정 |
| 배포 대상과 시작 조건 | 서버·스토어·레지스트리, 수동·push 자동·별도 승인 | 미정 |
| 배포 검증·실패 대응 | 선행 검사·환경 변경·데이터 이관·성공 확인·복구 방법 | 미정 |
