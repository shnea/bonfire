# 현재 핵심 기준

새 프로젝트를 정의할 때 필요한 만큼 목적·범위·핵심 결정을 채운다. 세부 조건은 관련 영역에 기록하고 여기에는 결론과 참조 위치만 유지한다.

- 기반 템플릿: Bonfire v1
- 프로젝트 이름: 미정
- 목적: 미정
- 현재 범위: 미정
- 기본 구성: workflow는 작업 절차, golden_path는 기준 관리. 전문 스킬은 필요에 따라 연결한다.
- 핵심 결정·제약: 미정
- 기술·운영 선택: 미정
- 실행·검증 명령: [검증 영역](domains/11-validation.md#실제-실행-명령)에 프로젝트의 실제 명령과 확인 상태를 기록한다.
- 중요한 예외: 없음
