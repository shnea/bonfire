# 제약·우선순위·운영 규모

필요시 확인: 일정·비용·규모·호환성·금지 조건이 선택에 영향을 줄 때.

적용 범위: 공통 정의 항목. 선택을 바꾸는 제약부터 확인한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 일정·예산 | 납기, 초기 비용·월 운영비 한도, 유료 서비스 허용 범위 | 미정 |
| 판단 우선순위 | 단순함·속도·안정성·성능·비용 중 충돌 시 무엇을 우선할지 | 미정 |
| 필수·금지 조건 | 반드시 쓰거나 쓰지 않을 기술·서비스·환경 | 미정 |
| 규모·연결 조건 | 예상 사용량·데이터량, 온라인·오프라인, 확인되지 않은 가정 | 미정 |
| 기존 자산·호환성 | 기존 코드·데이터·서비스·클라이언트와 유지해야 할 관계 | 미정 |
