# 화면·접근성·사용성

필요시 확인: 화면·사용자 문구·접근성·기기 대응을 바꿀 때.

적용 범위: 조건부. 화면이나 사람이 직접 사용하는 인터페이스가 있을 때 적용한다. CLI라면 명령·출력·도움말 기준으로 바꾼다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 정보와 행동의 순서 | 사용자가 먼저 볼 내용, 주요 동작, 탐색·진입 경로 | 미정 |
| 시각적 기준 | 기존 디자인·참고 화면, 색·글꼴·간격·공통 요소 | 미정 |
| 기기와 입력 방식 | 모바일·PC·키보드·터치, 확대·좁은 화면 대응 | 미정 |
| 접근성과 표현 | 읽기 쉬운 문구, 레이블·초점·색 외 상태 표시, 지원 언어 | 미정 |
