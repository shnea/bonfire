# 목적·사용자·성공 기준

필요시 확인: 최초 정의, 목적·사용자·성공 조건 변경.

적용 범위: 공통 정의 항목. 프로젝트가 해결할 문제를 이해할 때 가장 먼저 다룬다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 해결할 문제 | 지금의 불편, 만들려는 이유, 해결 후 달라지는 점 | 미정 |
| 주요 사용자 | 누가 사용하는지, 숙련도, 개인·팀·외부 고객 여부 | 미정 |
| 사용 상황 | 어디서·얼마나 자주·어떤 기기나 도구로 사용하는지 | 미정 |
| 핵심 가치와 성공 기준 | 사용자가 어떤 일을 마치면 유용한지, 결과를 어떻게 확인할지 | 미정 |
