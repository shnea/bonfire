# 문서·인수인계·기준 유지

적용 범위: 공통 정의 항목. 다음 사람·에이전트가 이어갈 수 있을 만큼 유지한다.

| --- | --- | --- |
| 첫 실행 안내 | 준비 사항, 설정, 실행·검사 명령, 새 환경에서의 확인 | 미정 |
| 상세 문서 범위 | 설계·사용법·운영 문서 중 필요한 것과 기준 문서의 위치 | 미정 |
