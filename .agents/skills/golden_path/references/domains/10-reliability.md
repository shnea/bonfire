# 성능·안정성·실패 대응

필요시 확인: 응답·자원 사용·긴 작업·중단과 복구를 다룰 때.

적용 범위: 공통으로 사용자 기대를 확인하고, 캐시·큐·이중화 등 추가 구조는 필요가 확인된 경우에만 선택한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 체감 성능과 자원 | 필요한 응답·처리 시간, 메모리·디스크·네트워크 제약 | 미정 |
| 중단과 재개 | 실패·중단 시 보존할 상태, 재실행·재시작의 기대 동작 | 미정 |
| 긴 작업 | 진행 표시·취소·백그라운드 처리 필요 여부 | 미정 |
| 성능 판단 근거 | 예상 규모에서 측정할 지표와 최적화가 필요한 조건 | 미정 |
