# 구조·코드·협업 규칙

필요시 확인: 폴더·모듈 경계·코드 규칙·협업 방식을 변경할 때.

적용 범위: 공통 정의 항목. 프로젝트 규모에 필요한 정도만 정한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 저장소·폴더 구조 | 단일·분리·모노레포 여부, 소스·테스트·문서·임시 결과 위치 | 미정 |
| 책임과 경계 | 모듈·계층·외부 연동의 경계, 공유 코드의 위치 | 미정 |
| 코드 규칙 | 이름·포맷·타입·오류 처리, 기존 스타일과 자동화 도구 | 미정 |
| 작업 판단 범위 | AI가 정할 수 있는 선택, 사용자와 논의할 결정 | 미정 |
| 협업 조건 | 다른 사람·에이전트의 변경 보존, 병렬 작업이 필요한 경우의 범위 | 미정 |
